DeepUnity LLM / GPU Engine + NPC — Overview

Scope: only post-2024 Assets/DeepUnity/InferenceEngine/LLM/* + Assets/DeepUnity/NPC/* + demos. Old ML/RL library excluded.

1. LLM inference — how it works

  • Full-GPU causal LLMs on Unity ComputeShaders. Per-frame coroutine pacing (no blocking): chunked prompt prefill + 1-token decode steps + async sampler readback. Framerate dial: InferenceEngine/BackendTradeoff.cs (BackendTradeoffTable: fetch bytes/frame, prefill steps/frame, decode tokens/frame) + FramePacing.cs / InferencePerf.cs.
  • Models: Qwen3.5-0.8B/2B (hybrid: 18× Gated-DeltaNet + 6× full GQA attention), Gemma3-270M, MiniCPM5-1B. Same pattern each.
  • Kernels: Assets/Resources/ComputeShaders/ — Qwen3_5CS / Gemma3CS / MatMulFP16CS / GQAInferenceCS / GLUInferenceCS / LmHeadInferenceCS / KVCache.hlsl (+ shared KV_READ/KV_WRITE, KV_FP16/KV_INT8 keywords).
  • Exporter: InferenceEngine/import_params.py --quant fp16|int8|int4 → Assets/Resources/Weights/weights_<model>_<size>_<quant>/.

2. Abstract class structure

  • LLM/Base/LLM.cs: abstract class LLM — every model implements: Config, IsReady, Warmup(), Predict(), Generate(), InitializeChatCore(), ChatCore(), CompactCore(), Save/RestoreConversationKVCore(), Release()/ReleaseSlow(). Shared: TokensPerSecond, Current/MaxContextTokens, Busy guard (refuses concurrent forwards), CancelChat() (stop at token boundary), COMPACT_PROMPT/HISTORY_HEADING("## MEMORY"), budgets UploadBudgetBytes (=BackendTradeoffTable.FetchBytesPerFrame), UploadFrameBudgetMs, UploadChunkFloats, DiskKVCache, CacheOwnerKey, main-thread release via DeepUnityDispatcher.
  • LLM/Base/LLMConfig.cs: arch descriptor (HiddenSize/VocabSize/NumLayers/HeadDim/Eos/Bos/Pad) + sampling presets DefaultTemperature/TopK/TopP/MinP/Presence/RepetitionPenalty. Each model forwards to its static *Config.
  • LLM/Base/LLMRegistry.cs: [LLMEntry] self-registration by reflection; game code uses string id ("Qwen3.5-0.8B", finetunes auto-found as weights_qwen3.5_<size>_<variant>_<quant>). Create(id,quant,kvQuant,maxLen).
  • LLM/Base/LLMPool.cs: refcounted share per (id,quant,kvQuant,maxLen) — one VRAM copy; tracks Claim/OwnsConversation. Release() → trickled ReleaseSlow().
  • LLM/DeepUnityDispatcher.cs: hidden MonoBehaviour pumping coroutines + main-thread queue (GPU calls are main-thread only).
  • Concrete per model (example Qwen3.5): LLM/Qwen3_5/Qwen3_5.cs (facade Qwen3_5ForCausalLM : LLM) + Qwen3_5Modeling/{Qwen3_5Config, Qwen3_5Model, Qwen3_5Weights, Qwen3_5Cache, Qwen3_5ChatTemplate, Qwen3_5TokenizerFast}. Gemma3/MiniCPM5 mirror it.

3. LLM abstract class — functions

Assets/DeepUnity/InferenceEngine/LLM/Base/LLM.cs — one line per member:

  • LLM() — ctor: ensures dispatcher, registers live model, hooks quit/play-mode teardown.
  • ~LLM() — finalizer: marshals Release() to main thread (GPU calls are main-thread only).
  • ReleaseAllOnQuit() — releases all live models before GfxDevice teardown.
  • HookAssemblyReloadTeardown() — releases all on script recompile (else orphaned buffers).
  • OnPlayModeChanged() — releases model on exiting play mode (editor).
  • Config — arch + sampling-default descriptor.
  • IsReady — true when weights uploaded + tokenizer parsed.
  • TokenizerReady — async tokenizer parse done (splits boot timing).
  • TotalWeightBytes / UploadedWeightBytes — manifest size vs resident bytes (paces walk-up prefetch).
  • WeightsLabel — id used in [GPU] residency log lines.
  • CurrentContextTokens / MaxContextTokens — live KV occupancy vs capacity (drives halt/compact logic).
  • ReleaseSlow() — trickle-frees buffers over frames (avoids 250–550 ms stall); default = sync Release().
  • Warmup() — compiles kernels + throwaway forwards; idempotent; auto-run by InitializeChat.
  • GetOrCreateTokenizer() — one parse per tokenizer file per session (~1 s + big GC, so cached).
  • Predict() — single forward over ids → logits tensor.
  • Generate() — free-form streaming generation from raw ids.
  • Guarded() — Busy guard: 2nd concurrent op refused with warning instead of corrupting KV.
  • AbandonGuardedOperation() — force-clears Busy after a StopCoroutine-killed op.
  • InitializeChat() → InitializeChatCore() — warmup + prefill (or disk-KV restore) the system prompt.
  • Chat() → ChatCore() — one templated user turn + streaming reply.
  • ChatToolResult() → ChatToolResultCore() — feeds tool JSON back as <tool_response> turn.
  • CancelChat() — cooperative stop at next token boundary; KV stays consistent.
  • Compact() → CompactCore() — summarizes chat, re-seeds KV as [system + ## MEMORY + summary].
  • SaveConversationKV() → SaveConversationKVCore() — persists full KV/SSM + sampler + transcript blob.
  • DeleteConversationKV() — deletes snapshots so next open starts fresh.
  • TryRestoreConversationKV() → ...Core() — restores snapshot after hash validation; false = re-prefill.
  • Release() — frees all GPU buffers; idempotent.
  • OnReleased() — unhooks editor event, idles phase, suppresses finalizer.
  • WarnIfNotInResources() — warns when weights/tokenizer path won't ship in builds.
  • ResolveParamsDir() — resolves weights folder (flat → organized → legacy).

4. Developer interface

LLM llm = LLMPool.Acquire("Qwen3.5-0.8B", LLMQuant.INT8, KVQuant.FP16, 8192);
yield return llm.Warmup();                 // kernel compile, idempotent
yield return llm.InitializeChat(sysPrompt); // chunked prefill or KV restore
yield return llm.Chat(playerText, s => ui.Append(s), max_new_tokens:1024,
  temperature:0.8f, top_k:20, top_p:1f, presence_penalty:2f);
llm.CancelChat();                           // safe interrupt
yield return llm.Compact(sysPrompt);        // summarize→re-seed "## MEMORY"
yield return llm.SaveConversationKV(npcId, transcriptJson);
yield return llm.TryRestoreConversationKV(npcId, ok=>{...}, sysPrompt);
LLMPool.Release(llm);                       // or llm.Release()/ReleaseSlow()

Low-level: Predict(ids) single forward → logits; Generate(ids, …) raw-id streaming. Sampling defaults on signatures are neutral — pass llm.Config.Default* for the model preset.

5. Weights — load/store

  • Files: .bin (fp16, 2 halves/uint) | .int8.bin + .scales.bin (weight-only symmetric int8, 4/uint, 1 fp16 scale/output row) | .int4.bin + .scales.bin (Q4_0-style, 8 nibbles/uint, 1 scale/32 weights). Embedding + norms stay fp16. LLMQuant in Base/LLM.cs.
  • Loader e.g. Qwen3_5Weights.cs: ctor builds only a manifest; thread-pool FileStream reads (≤4 in flight, pooled byte[]) → queue → main-thread UploadPump() coroutine creates ComputeBuffer<uint> lazily and SetData-slices under LLM.UploadBudgetBytes/frame. IsReady after drain; ResidencyLog logs Loading/Resident/Released. Dispose/DisposeSlow frees ~64 MB/frame.
  • Where: LLM/*/ *Weights.cs, resolved by LLM.ResolveParamsDir() (flat Resources/Weights/ → organized → legacy).

6. KV cache — load/store

  • Buffers e.g. Qwen3_5Cache.cs: full-attention layers kCaches/vCaches (token-major, preallocated to maxModelLength); DeltaNet layers convStates/recurrentStates (always FP32). All stride-4 uint; count shrinks by KVQuantUtil (FP32:1, FP16:2, INT8:4 elems/uint). INT8 KV = asymmetric per-(token,head) scale+zp (+ kScaleZp/vScaleZp).
  • Disk: SaveYielding/LoadYielding — AsyncGPUReadback (≤SaveReadbacksInFlight) + worker-thread file IO to .tmp→atomic move; header magic Q5KV, v2, contextHash(weights path+capacity+kvQuant+prompt), kvQuant, tokens, extraState. Any mismatch = miss → recompute. Upload chunked under UploadFrameBudgetMs/UploadChunkFloats.
  • Files in Application.persistentDataPath/DeepUnity/: system prompt qwen35_prompt_<owner|hash>.kv (FNV-1a over ids+path+capacity+kv), conversation qwen35_conv_<owner>.kv (+ extra blob: tokenSeen, isFreshlyInitialized, userState=transcript). Toggled per instance by DiskKVCache/CacheOwnerKey/SystemPromptDiskCache.

7. NPC script

  • Location: Assets/DeepUnity/NPC/NPCChatBase.cs (abstract) + NPCDialogueWindow.cs (window base, INPCChatWindow/INPCToolQuestionWindow/INPCGiveItemWindow), NPCInteractPrompt.cs, NPCDecision.cs, FaceSync.cs, ConversationAudioDucker.cs.
  • Subclasses (presentation only): Tutorials/ChatDemo3D/Scripts/NPCInteractor3D.cs, Tutorials/ChatDemo2D/Scripts/NPCInteractor2D.cs (+ChatWindow2D), Tutorials/AnyaChatDemo/Scripts/NPCInteractorAnya.cs. Scene builders: Tutorials/*/Editor/*Builder.cs.
  • What it owns: inspector (model, quantization, maxContextLength, sampling(-1=preset), historyMode, cacheKVCache, ttsModel/ttsVoice, usePrefetchZone/prefetchRadius); EnsureLlm() via LLMPool.Acquire + Warmup + InitializeChat(EffectiveSystemPrompt); prefetch/residency zone (slow stream on entry, resident inside, unload on exit); dialogue state machine (open/ask/stream/close, Escape = CancelChat); transcript + HistoryMode.ResetEveryTime / ResumeFromCompact (live-KV → disk Save/RestoreConversationKV → re-prefill system+## MEMORY+turns; auto-Compact() at limit); tools (AskUserQuestion/GiveItem panels + INPCToolProvider reads, ChatToolResult loop); per-token TTS fan-out + talk animation + context-fill bar (Current/MaxContextTokens).
  • Effective system prompt = [# Tools block] + descriptionAndRules + ## MEMORY/compactSummary (see Editor/EffectivePromptWindow.cs).
